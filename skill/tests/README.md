# skill 壓力測試

用 23 份不同狀況的【虛構】資料檢查 skill 的程式是否穩健。

```
bash run_stress.sh              # 預設「只含各區合計」模式
bash run_stress.sh 逐月          # 逐月模式
```

| 情境 | 預期 |
|---|---|
| 只有 2 區、各區陽性率相同、某區全年陽性為 0、兩區都是 0 | 完整跑完；報告文字依資料調整 |
| 全部陽性為 0 | 中文說明後停止（無法做比較檢定） |
| 某區只有 1 個月、跨年 18 個月且整月缺、人數很少 | 完整跑完（人數很少時改用 Fisher 與模擬 p 值） |
| 欄位名稱不同 | 中文說明缺哪個欄位後停止 |
| 多餘欄位、沒有疫苗接種人數欄、人口數各月不同 | 完整跑完（人口數各月不同時提醒並取最新月） |
| 不同寫法其實是不同的區 | 中文說明被合併的原始寫法後停止 |
| 空白變化、全形、月份寫法混用、民國年、Big5 編碼 | 完整跑完 |
| 行政區空白、人數非整數、人口數為 0 | 完整跑完（問題列排除並記錄） |
| 某區全期陽性 < 5、陽性率很低 | 完整跑完（合計模式遮蔽該區；加註檢定力有限） |

這是工程上的檢查，不代表在 Claude 上實際使用的結果；請另外上傳 skill 試用。

# 〔期間〕篩檢分析成果包

> **注意：本成果包含原始資料（01）與逐列資料（02）。** 打包、存放與傳遞都要依單位規定；給主管通常只需要 `06_報告`。

〔一句話說明分析目的與資料來源；若為虛構資料請註明。〕

## 資料夾說明

| 資料夾 | 放什麼 |
|---|---|
| `00_分析計畫/` | 分析計畫、報告設定 |
| `01_原始資料/` | 原始資料，**永遠不修改** |
| `02_清理後資料/` | 分析用資料、修正與排除紀錄 |
| `03_程式碼/` | 依編號順序執行的程式碼；每支程式最上方都寫明輸入檔與輸出檔 |
| `04_結果表格/` | 表1–表7 |
| `05_圖表/` | 圖1–圖2 |
| `06_報告/` | 互動報告（HTML，雙擊用瀏覽器開啟） |

## 怎麼重跑

建議在 Claude 的檔案建立功能（雲端沙箱）裡重跑。若要在自己電腦執行：只執行自己產生或逐段看過的程式；別人傳來的成果包不要直接執行；安裝 Python 與套件前先問單位資訊人員。
需要 Python 3 與 pandas、scipy、matplotlib；表6、表7 另需 statsmodels。在這個資料夾依序執行：

```
python 03_程式碼/01_clean.py
python 03_程式碼/02_descriptive.py
python 03_程式碼/03_inferential.py
python 03_程式碼/04_report.py
python 03_程式碼/05_package.py
```

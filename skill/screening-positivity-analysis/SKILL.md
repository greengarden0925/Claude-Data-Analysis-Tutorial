# 篩檢陽性率分析（行政區 × 月份）

把一份「每列 = 某月某區」的篩檢統計，變成可查核、可重跑、分資料夾歸檔的分析成果與互動報告。
`scripts/` 內是已驗證過的程式，優先使用，不要從頭重寫。

## 適用資料

必要欄位（名稱不同時，先列出對應關係請使用者確認，再改名）：

| 欄位 | 內容 |
|---|---|
| 月份 | YYYY-MM（YYYY/M 會自動轉換） |
| 行政區 | 區名或代號 |
| 人口數 | 該區總人口（各月相同；**不可跨月加總**） |
| 篩檢人數 | 人數（整數） |
| 陽性數 | 初篩陽性人數（整數） |

其他欄位保留但不分析，並在報告的限制中說明。

## 鐵則

1. **先問目的再分析**：請使用者用一兩句話說明誰要用、想回答什麼。沒有目的時，用預設的三個問題：各區差多少？差異是真的還是剛好？夠不夠拿來做決定？
2. **先給程式碼，等使用者回覆「執行」才執行**：凡是會讀寫資料或計算的程式都適用。寫計畫文件、建立資料夾、說明架構可以直接做。先給程式碼是為了抓分析錯誤，**不是資安檢查**。
3. **安全**：確認資料是虛構或已去識別化、且單位允許使用；提醒處理非公開資料時關閉網路存取。背景說明只寫分析目的，不寫機關、人名、未公開決策。
4. **不改原始檔**；所有數字由程式算出，不自己編。
5. **用詞**：說「篩檢陽性率較高」，不說「高風險」「警示」「排名第幾」；率與人數一起呈現；顯著 ≠ 重要。
6. **缺值不補、邏輯錯誤不改**：一律排除並記錄，交給使用者決定是否回頭查。

## 流程

### 步驟 0：確認目的與資料夾
1. 問目的（見鐵則 1），把它寫進 `00_分析計畫/報告設定.json`（範本：`assets/報告設定範本.json`；真實資料把「虛構資料」「提供下載逐列資料」設為 false）。
2. 建立資料夾：`00_分析計畫`、`01_原始資料`、`02_清理後資料`、`03_程式碼`、`04_結果表格`、`05_圖表`、`06_報告`。
3. 原始 CSV 放進 `01_原始資料/`（裡面只能有 1 個 CSV）；把 `scripts/` 的 6 個檔案複製到 `03_程式碼/`；用 `assets/README範本.md` 建立最上層 `README.md`。

### 步驟 1：體檢與清理 → `03_程式碼/01_clean.py`
預設規則：完全重複只留一筆；行政區去空白、英文大寫；月份轉 YYYY-MM；篩檢人數缺值排除；陽性數 > 篩檢人數標「待查」並排除。
先把規則與程式重點（讀哪個檔、有沒有改原檔、存到哪裡）給使用者看，使用者若要不同規則就修改程式。執行後回報：原始 → 去重 → 分析用列數，以及各類問題筆數。
程式內建檢查：分析用資料若出現重複的「月份 × 行政區」會停止，這通常代表清理規則把不同的列合併了，要回頭檢查。

### 步驟 2：分析計畫 → `00_分析計畫/分析計畫.md`
依 `references/分析計畫範本.md` 填寫：問題 → 方法 → 為什麼適合 → 假設 → 怎麼檢查 → 怎麼解讀，以及「不能回答的問題」。再用範本的六點清單自我審查，修正後給使用者確認。

### 步驟 3：描述性統計 → `02_descriptive.py`
表1 各區（納入月數、缺的月份、人口數、篩檢人數、粗篩檢率、陽性數、篩檢陽性率、Wilson 95% CI）、表2 每月、表3 各區每月、圖1、圖2。執行後請使用者驗算 1 個數字（陽性數 ÷ 篩檢人數）。

### 步驟 4：推論性統計 → `03_inferential.py`
表4 卡方檢定（含最小期望次數）、表5 兩兩比較（差異 95% CI、Holm 校正）、表6 敏感度分析（行政區＋月份的二項式 GLM；φ ≤ 1 用概似比卡方檢定，φ > 1 用 quasi-F）、表7 考慮月份後的兩兩比較。需要 statsmodels，沒有時表6、表7 自動略過，並告知使用者。
最小期望次數 < 5 時，改用 Fisher 精確檢定或合併區域，先和使用者討論。

### 步驟 5：互動報告 → `04_report.py`
讀 `報告設定.json` 與表格，產生 `06_報告/互動報告.html`（單一檔案、資料內嵌、不連外部網路）。結構：目的 → 重點摘要 → 資料概況 → 描述 → 推論 → 如何應用 → 實務建議（可由數據支持／需進一步查證）→ 限制與方法。重點摘要與建議由資料自動產生；產生後讀出重點摘要給使用者核對。

### 步驟 6：歸檔打包 → `05_package.py`
檢查 00–06 與 README.md 是否齊全、印出樹狀圖、打包 zip。提醒：成果包含原始與逐列資料，真實資料依單位規定存放與傳遞，給主管通常只需要 06_報告。

## 解讀規則

詳見 `references/解讀規則.md`。重點：篩檢陽性率 ≠ 盛行率；陽性 ≠ 確診；粗篩檢率的分母是區總人口、不是符合資格人口；信賴區間重疊 ≠ 沒有差異；建議行動不點名特定區為問題區。

## 完成時回報

1. 資料夾樹狀圖與 zip 檔名。
2. 關鍵數字：分析用列數、整體篩檢陽性率、卡方檢定結果、兩兩比較有差的對數、考慮月份後是否改變。
3. 請使用者自己查核的 3 個數字（總篩檢人數、總陽性數、任一區的陽性率）。
4. 這份資料不能回答的問題。

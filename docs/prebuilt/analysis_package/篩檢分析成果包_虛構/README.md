# 篩檢分析成果包（虛構資料）

這是「Claude 辦公實戰」課程的參考成果包，示範一次完整分析的檔案應該怎麼分資料夾擺放。
**所有資料皆為電腦隨機產生的虛構資料，A–H 區為代號，不代表任何真實地區、機關或個案。**

## 資料夾說明

| 資料夾 | 放什麼 |
|---|---|
| `00_分析計畫/` | 分析計畫：情境、分析問題、方法、假設檢查、不能回答的問題、結果摘要 |
| `01_原始資料/` | 原始資料，**永遠不修改** |
| `02_清理後資料/` | 分析用資料（91 列）、修正與排除紀錄 |
| `03_程式碼/` | 依編號順序執行的程式碼 |
| `04_結果表格/` | 表1–表6（描述性統計、推論性統計、敏感度分析） |
| `05_圖表/` | 圖1–圖2 |
| `06_報告/` | 互動報告（HTML，雙擊用瀏覽器開啟）、一頁 Word 摘要 |

## 怎麼重跑

需要 Python 3 與 pandas、scipy、matplotlib；表6 另需 statsmodels（沒有時會自動略過）。
在這個資料夾（最上層）依序執行：

```
python 03_程式碼/01_clean.py
python 03_程式碼/02_descriptive.py
python 03_程式碼/03_inferential.py
```

## 檔案命名規則

- 資料夾與程式用數字開頭，照執行順序排列。
- 表格與圖表用「表1_」「圖1_」開頭，和報告中的編號一致。
- 原始資料不覆蓋；每一步的輸出都寫到下一個資料夾。

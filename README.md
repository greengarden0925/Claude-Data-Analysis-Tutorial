# Claude 辦公實戰：讓資料分析與報告製作更快、更簡單

給公共衛生師的 60 分鐘實作課講義，以 Dashboard 網頁呈現，Step by step 操作。

## 內容
- `docs/index.html`：講義 Dashboard（單一檔案，無外部相依，可離線開啟；提示詞可一鍵複製）
- `docs/sample-data/screening_demo.csv`：虛構示範資料（含刻意埋入的髒資料）
- `docs/sample-data/screening_clean_answer.csv`：解答用乾淨版
- `scripts/make_sample_data.py`：資料產生腳本（固定亂數種子，可重現）

## 本機預覽
直接用瀏覽器開啟 `docs/index.html`。

## 發佈成網址（GitHub Pages）
Repo → Settings → Pages → Source 選「Deploy from a branch」，Branch 選要發佈的分支，資料夾選 `/docs`。

## 注意
所有資料皆為電腦隨機產生的虛構資料，不代表任何真實地區或個案。工具介面與功能以開課當天實際畫面與官方說明為準。
